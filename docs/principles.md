# What "Responsible Web Presence" Means

These six commitments apply to every site we build and every recommendation we make.
They are also a selling point. Put them on the sales page.

1. **Owned, not rented.** The client owns the domain (in their name and their registrar
   account), the content, and the code. Social profiles point *to* the site, not the
   other way around. Nothing is locked into us or into a single platform.

2. **Private by default.** There are no third-party trackers, ad pixels, or cookie banners,
   because the sites don't use those cookies. If the client wants analytics, use a
   cookieless, privacy-first tool (Plausible, Fathom, or Cloudflare Web Analytics). We share
   only the minimum personal information needed: no home address, and a contact form or
   business email instead of a personal one.

3. **Accessible to everyone.** Target WCAG 2.2 AA: real text contrast, alt text, keyboard
   navigation, semantic headings, readable type sizes, and respect for reduced-motion preferences.

4. **Light and fast.** The aim is a page weight under 1 MB, no unnecessary JavaScript, optimized
   images, and good Core Web Vitals. A fast site is better for people on slow connections, for
   search, and for the planet.

5. **Secure.** HTTPS everywhere, sensible security headers, 2FA on every account we touch, and
   a password manager handoff. There's no admin panel to hack when the site doesn't need one.

6. **Honest.** Real photos, real credentials, and a real voice. No fake reviews, inflated
   claims, or dark patterns.
